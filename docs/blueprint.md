# **App Name**: WeldOrder

## Core Features:

- Order Placement: Allow customers to place welding orders online with details like name, contact information, address, welding work type, and size details.
- Photo Upload: Enable customers to upload exactly 2 photos of their welding work or design.
- Order Submission: Receive customer orders in the app's order system and display a success message upon submission.
- Contact Us Page: Provide a 'Contact Us' page with call and WhatsApp buttons for easy communication with the welding shop.

## Style Guidelines:

- Primary color: Deep blue (#2962FF) to reflect the precision and strength associated with welding.
- Background color: Light gray (#F0F2F5) to ensure content is easily readable.
- Accent color: Warm orange (#FF8F00) to draw attention to important action items like 'Place Order' button.
- Body and headline font: 'Inter' (sans-serif) for a modern and clean user interface.
- Use simple, outline-style icons to maintain a clean and modern look.
- Use a simple and intuitive layout with clear sections for each function to make the app user-friendly.
- Subtle animations such as a fade-in effect when transitioning between screens to improve the user experience.
